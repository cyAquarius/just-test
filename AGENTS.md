# just-test

- Default to Chinese for collaboration; keep code identifiers and commands in English.
- This repository is a reusable testing toolkit. Do not introduce application-specific packages, dependencies, schemas or cases.
- Framework code belongs under com.just.test.smarttest.
- Demo-only code belongs under com.just.test.smarttest.demo in src/test.
- Preserve Java 8 compatibility unless an explicit migration is approved.
- Java builds and tests use Maven directly.
